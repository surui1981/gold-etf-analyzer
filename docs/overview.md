## 1. 项目概述

面向**个人黄金投资者**（尤其做**中短期 ETF 波段**）的一站式数据参考平台：

1. **量化多空** — 把技术面、宏观面、消息面三维度按权重加权成一个 0-100 的「综合趋势指数」，看一眼就知道现在偏多还是偏空。
2. **持仓闭环** — 你的开仓 / 加减仓 / 清仓都进系统，**实时盈亏、胜率、最大回撤、收益曲线**自动算。
3. **决策可解释** — 系统给出「买 / 加 / 持有 / 减 / 卖」建议时，每一条都附**理由明细**（指数分位、持仓状态、阈值依据），而不是黑盒。
4. **多市场覆盖** — 纽约金（COMEX） / 上海金（Au99.99） / 黄金 ETF（518880） / 白银 ETF（562800） / 纽约银（SI=F），单一平台对照。
5. **本地优先** — 持仓、账本、消息面打分、推送订阅全部 SQLite 本地存，**不上云**。

**投资指引基准**：**纽约金（COMEX GC）**——连续交易、夜盘覆盖国内休市时段，对国内金价具领先指示意义；ETF / 上海金作国内对照与交易标的。

## 2. 当前产品能力（不带版本号）

> **能力全景**（含首次落地版本）见 [docs/releases/index.md](releases/index.md)。本节只列"产品今天能做什么"。

### 2.1 评估体系
- **三面评估**：技术面 30% + 宏观面 40% + 消息面 30% → 综合趋势指数 0-100
- **技术面 5 维**：结构 / 动量 / 支撑 / 动能（RSI）/ 回撤 —— 权重可调
- **宏观面 11 因子**（V0.119.0）：美元指数 / 美债 2Y·10Y·30Y / 10Y-2Y 利差 / 10Y 实际利率 / VIX / 央行购金 / **美国·中国·欧洲政府债务/GDP** —— 7 个日频因子阈值可动态化（近 252 日滚动 90/10 分位），4 个低频因子（央行购金 + 3 个政府债务）走硬编码兜底
- **消息面每日 3 次打分**：1:2:3 加权，越晚权重越高
- **消息面未打分 → 综合指数 pending**（不静默回退中性）

### 2.2 决策与持仓
- **5 档决策**：买入 / 加仓 / 持有 / 减仓 / 卖出（+ 缓冲档 HOLD_CAUTIOUS）
- **多账本**：默认账户 + 自定义账本，顶栏切换器
- **双单位持仓**：份数（ETF 标准）+ 克数（实物金 / 积存金）
- **收益曲线 + 最大回撤** + **获利分析**（胜率 / 盈亏比 / 平均持仓天数）
- **决策可解释性**：每条建议附理由明细 + 红绿方向标注

### 2.3 多市场对照
- **三市场基础**：纽约金 / 上海金 / 黄金 ETF
- **白银追踪**：白银 ETF + 纽约银（Yahoo Finance provider + 自动降级 mock）
- **央行购金**：WGC 季度数据 2014Q1–2026Q2 + Top 10 买家榜
- **多时间框架**：60D / 52W / 24M 三档
- **ETF vs 克价** 对照面板（真实价格双图）

### 2.4 消息面 / 研判
- **研判复盘**：T+1 / T+3 / T+5 命中 + 校准曲线 + 依据标签胜率
- **首页综合研判结论卡**：一行结论 + 三维分值条 + 一致性判定 + 黄金/白银切换
- **首页内嵌消息面打分器**：3 槽位状态 + 有效分值 + 内嵌编辑器，全程不跳页

### 2.5 推送 / 告警 / 部署
- **4 类告警规则**：指数跨档 / 单日波动 ≥X% / 自定义时段 / T+N 命中
- **4 渠道推送**：浏览器通知 / Web Push（VAPID）/ SMTP 邮件 / Server 酱微信
- **公开部署**：Docker 多阶段 + Nginx + Let's Encrypt + 自动续签（详见 [deployment.md](deployment.md)）

### 2.6 智能分析
