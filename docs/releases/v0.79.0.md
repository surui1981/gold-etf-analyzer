## 一、Step G · 回测权重嵌套扩展（P0，commit `dbf9239` `77d33a5` `43cab52`）

### 能力

- **嵌套权重网格**：`tech/macro/news` 三层网格内**每个**都支持内部 5 维子网格（例：tech=0.5 时扫描 `结构/动量/支撑/动能/回撤` 各自 3 个候选 → 共 243 组合）。
- **异步回测接口**：`POST /api/v1/backtest/run-async` → 立即 202 + `task_id` + `Location` 头；`GET /api/v1/backtest/result/{task_id}` 状态机：pending → running → completed / failed。
- **UI 高级模式**（`/backtest`）：tech_5 / macro_5 子网格编辑器 + 异步进度条。

### 数据需求

- `daily_snapshots.tech_detail`（V0.79.0 新增列）：5 维度 JSON `{name: {score, weight, contribution}}`。
  **历史 24 条无法回溯补**（上游 K 线只覆盖其中 16-17 天，task #162 结论），
  故本步**只对未来快照生效**，回测结果将逐步真实化。

### 适用客户

- 调参深度用户：能从「综合权重」下沉到「维度权重」做精细回测。
- 异步接口允许「扫 243 组合」无需浏览器常驻。

## 三、Step F · 技术面 5 维度重构（组内平均，P1，commit `45044f6` `020ab5e` `479bd32` `999decf` `f60e98c`）

### 背景

V0.78.0 实测：4 个维度（结构/动量/支撑/动能）都围绕「均线 + 价格动量」算 → 内部高度相关；
加权后实质变成「4 倍趋势 + 1 倍回撤」→ 回撤信号被稀释。

### 能力

- **3 组权重**：趋势组（结构+动量）= 0.50 / 超买组（动能+支撑）= 0.30 / 风险组（回撤）= 0.20。
- **`TrendService.combine_by_group()`** 静态 helper：组内平均后再加权。
- **`TrendIndexOut.composed_by: Literal["weighted", "grouped"]`** 标识当前合成方式。
- **`GoldTrendOut/SilverTrendOut.tech_composed_by`** 顶层字段透传。
- **`WeightConfig.group_combine: bool = True`**（默认开启）+ UI 权重配置页第 4 卡切换。
- **回滚通道**：UI 切「单维度加权（历史）」或 `PUT /api/v1/settings/weights {"group_combine": false}` 即恢复历史行为。

### 实测

合成数据（seed=42，100 样本）：
- 单维度加权：avg_tech=49.40, hits=34/100 = 34.00%
- 组内平均：  avg_tech=49.49, hits=33/100 = 33.00%
- diff:       avg_tech=0.088, hits=1

**结论**：方法可行（差距 1/100，远小于随机波动）；默认保留 `group_combine=True`（推荐方案 2）。

`docs/parameter-evaluation/sharpe_compare_2026-10-07.md` 完整对比数据。

## 四、Step H · 样本阈值分层（P2，commit `5df2707`）

### 能力

- **MIN_SAMPLES_OVERALL = 10**：总体命中率可信度下界（原 20 太高，本地客户难以达到）。
- **MIN_SAMPLES_BUCKET = 5**：分维度样本阈值（命中分桶 / 方向分桶 / 校准分桶 / 标签分桶）。
- **sample_warning 升级**：`bool` → `Optional[str]`。服务端填提示文案，前端不再「哑标记」。
  - 总样本 < 10 → "样本仅 N 天，统计波动较大，仅供参考"
  - 单桶样本 < 5 → 该桶标记「样本偏少」灰色 tag

### 适用客户

- 早期用户能立即看到「样本不足」的诚实披露，不再被高 hit_rate 误导。
- 阈值降低后，复盘接口（`/review/stats` / `/review/hint`）数据更有用。
