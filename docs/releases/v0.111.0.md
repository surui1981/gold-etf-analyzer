## 一句话

应用里一直没有「我自己的文档」入口（`/report` 是**复盘报告**，由持仓/交易数据自动
生成，另一回事）。现在首页多一个场景卡 → 点进去是一个可搜索的**报告档案柜**：
上传 `.html`，填标题 / 日期 / 分类 / 标签 / 摘要，点「查看」新标签页打开。

用户原话：「我们首页添加一个报告上传的板块，用户可以上传 html 格式的报告，并提供
客户查看显示，然后建立存单方便用户查看。」

「存单」经确认为**元数据登记表**（可搜索筛选的字段集合），不是书签。

## ⚠ 安全设计：你要的 UX，隔离照样给

「新标签页打开 + 完整渲染」和「切断 origin 边界」并不冲突 —— 靠**响应级 CSP**
即可，渲染保真度分毫不动：

```
Content-Security-Policy: sandbox allow-scripts allow-popups;
                         connect-src 'none'; form-action 'none';
                         base-uri 'none'; object-src 'none'; frame-src 'none'
```

### 为什么要这么较真

当前生产 `.env.prod` **没有 `AUTH_ENABLED`** ⇒ 认证关闭、不签发 cookie、
`user_id` 恒为 `LEGACY_USER_ID=1`，连 `ADMIN_TOKEN` 校验都被
`middleware/admin_auth.py:9-10` 跳过。

也就是说，真实风险**不是**「偷 session」，而是：一份裸发的同源 HTML 里的 JS 能
直接调**全部** `/api/v1/*` 写端点 —— 改 V0.110.0 的评估权重、删收藏、改告警规则，
等于「以你的身份操作这个系统」。

### 每条指令各自封住什么

| 指令 | 效果 |
|------|------|
| `sandbox`（**不带** `allow-same-origin`） | 文档进入 **opaque origin** → 读不到 localStorage / cookie，够不到 `window.parent` |
| `connect-src 'none'` | fetch / XHR / sendBeacon / WebSocket 全封 → **调不动任何接口** |
| `form-action 'none'` | 提交不了表单 |
| `object-src 'none'` / `frame-src 'none'` | 塞不进插件 / 子框架 |
| **刻意不给 `default-src`** | 否则会连带禁掉外部 CSS / 字体 / 图片，把报告渲染打残 |

配套响应头：`X-Content-Type-Options: nosniff`（防 MIME 嗅探）、
`Content-Disposition: inline`（内联渲染而非下载）、
`Cache-Control: no-store`。

### 残留与取舍

报告仍可 `<img src="http://evil/?x">` 外发请求 —— 但此时它已无任何可偷的数据
（读不到 localStorage、连不上 API），等于废动作。

**明确不做**：应用级安全响应头中间件。要不动 `marked.min.js` + 大量内联脚本的
现存页面，风险远大于收益；先只对**上传响应**做定向 CSP。

### 3 条配套硬规矩

1. 上传物**绝不落 `static/`** —— 那里是 SW `cache-first`（`sw.js` install 段）
   + 限流豁免（`config.py:145` 的 `rate_limit_skip_static=True`）区，进去就永久回放且不限速
2. 落盘用 `uuid4().hex`，**原始文件名只当展示元数据**（前端 `escapeHtml`），绝不参与路径拼接
3. nginx 需补 `client_max_body_size` —— 默认 **1MB**，不放开直接 413，应用连日志都看不到

## 数据模型

新建真表 `reports`，**不**复用 `app_settings` KV —— KV 无 `user_id`、`key` 是
`String(64)` 主键、整值替换、内存 TTL 缓存，结构上做不了列表。

| 列 | 类型 | 说明 |
|----|------|------|
| `user_id` | Integer FK users.id | 归属用户；单用户模式下恒为 1 |
| `title` | String(200) | 报告标题 |
| `stored_name` | String(64) UNIQUE | 磁盘文件名 `uuid4().hex.html` |
| `original_name` | String(200) | 上传时原始文件名（**仅展示**） |
| `size_bytes` | Integer | 字节数 |
| `report_date` | Date NULL | 报告自身日期（可与上传日不同） |
| `category` | String(32) | 分类，索引 |
| `tags` | Text | JSON 数组（去重 + 字母序） |
| `summary` | Text | 一句话摘要 |
| `created_at` / `updated_at` | DateTime | 服务端时间戳 |

分类预置：`研报 / 持仓 / 复盘 / 宏观 / 资金 / 其他`（可自由输入新分类）。

落盘目录 `data/reports/` —— 该目录在 systemd unit 的 `ReadWritePaths` 白名单内
（`ProtectHome=read-only`）；换任何别处在生产会 `Read-only file system`，而测试照过。

**迁移**：`migrations/versions/p2q3r4s5t6_reports.py`，`down_revision = "n1o2p3q4r5"`，
抄上一版的 `_table_exists()` 幂等守卫。

> ⚠ 不跑 `alembic autogenerate` —— `models/__init__.py` 现在就漏了 `news_feed`
> 和 `user_news_favorite`，autogenerate 会提议删表。**手写迁移**。

## 端点（8 个，`prefix="/reports"`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/upload` | multipart：`file` + `title` / `report_date` / `category` / `tags` / `summary` → 201 |
| GET | `` | 列表，`q` / `category` / `tag` / `limit` / `offset` → `{items, total}` |
| GET | `/{id}` | 单条元数据 |
| PATCH | `/{id}` | 改元数据（不动磁盘文件） |
| DELETE | `/{id}` | 删行 **+ unlink 磁盘文件** → 204 |
| GET | `/{id}/content` | `FileResponse` + 上述安全头 |
| GET | `/categories` | 分类 distinct，喂筛选下拉 |
| GET | `/stats` | 侧栏统计 |

分层照抄 `user_news_favorite` 五件套：`models/` `schemas/` `repositories/` `services/` `endpoints/`，
外加 `dependencies.py` 的 `get_report_repository` / `get_report_service`。

### ⚠ 路由顺序

`/categories` 与 `/stats` **必须注册在 `/{report_id}` 之前**。FastAPI 按声明顺序
匹配路由，否则 `/categories` 会被当成 `report_id="categories"` 走进详情分支报 422。
（已各有一条测试锁住。）

### ⚠ 上传校验（4 道，缺一不可）

1. 扩展名 `.html` / `.htm`
2. `len(content) <= 20MB`（同时在 nginx 设 `client_max_body_size 20m`）
3. 去 BOM / 首尾空白后必须以 `<` 开头 —— 挡掉把 `.exe` 改名成 `.html`
4. **分块读并累计**，超限即中止 —— 不把伪装成 `.html` 的 500MB 文件整个读进内存

入库失败会 `unlink` 已落盘的孤儿文件。

### 沿用的仓库惯例

- repo 每个方法首行 `resolve_user_id(user_id)`（`utils/user_scope.py`）
- 跨用户 `get()` 返回 `None` 而非 403（沿用 `ai_chat` 的理由：不泄露存在性）
- PATCH 用 Core `update()` + `expire_all()`，否则 identity map 里的旧值会被返回
- 列表 / 计数的筛选谓词**故意重复**而非抽公共函数 —— 抽出来会让两处都要改，
  漏改一处就是「列表和总数对不上」的分页 bug

## 顺手修的两个既有缺陷

### 1. `scripts/check_routes.py` 门禁会假失败（SIGABRT）

`_start_in_process_server` 原本返回 `thread`，**成功路径从不置
`server.should_exit`** —— daemon uvicorn 线程在解释器收尾时仍在写 stdout，撞出：

```
Fatal Python error: _enter_buffered_busy: could not acquire lock for
<_io.BufferedWriter name='<stdout>'> at interpreter shutdown,
possibly due to daemon threads
```

门禁以 **134（SIGABRT）** 假失败收场。多一条路由就改变时序 —— 本改动下 4 次里
炸 1 次，基线 5 次不炸纯属运气。

改为返回 `server` 句柄 + 新增 `_stop_in_process_server()`，`main()` 用
`try/finally` 优雅停机。修后连跑 6 次全部 exit=0。

### 2. `_escape_like` 转义了但没接上 —— 搜通配符反而搜不到

`reports.py` 的 `_escape_like` 把 `%` 转义成 `\%`，但每个 `.like()` 都**没有**传
SQLAlchemy 的 `escape=` 参数。SQLite 默认不把反斜杠当转义符，于是 `100\%` 变成
「字面反斜杠 + 通配符」，用户搜 `100%` 一条都搜不到。

**少传 `escape=` 比不转义更糟**：不转义是全命中（结果脏），错误转义是零命中
（用户以为搜索坏了）。已全部改为 `.like(pattern, escape="\\")`，并在函数 docstring
里写明这个耦合关系。回归锁：`test_list_escape_like_wildcard`。

## 部署注意

1. **nginx 补 `client_max_body_size 20m;`**（默认 1MB，不放开超限直接 413，
   应用连日志都看不到）→ `nginx -t` → `systemctl reload nginx`
2. **重启后端** —— `StaticFiles` 是分裂脑：页面 HTML 改完即时生效，但
   **Python 路由冻在 uvicorn 进程内存里**，不重启新端点就是 404
3. `python-multipart` 必须在 `.venv` 里真的装上 —— 它是**运行时**依赖
   （FastAPI 按需导入），缺了不会在启动时报错，而是**请求时 500**
