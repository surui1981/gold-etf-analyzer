# V0.106.0 · 今日要闻顶 nav 提级 + scheduler 6h→4h 加密

> 日期：2026-10-19
> 类型：体验改进（UX enhancement）—— 提升「今日要闻」可达性 + 加密更新频率
> 前置版本：V0.105.0

## 用户原话

> 当前今日要闻页面连接 提升到 导航栏 首页之后 决策之前，并且更新策略也没有实现，修改成每四小更新一次财经新闻

## 问题与目标

**问题 1**：V0.102 起的「今日要闻」(`/headlines`) 藏在「情报」scene 下的 5 个子页之一（消息面评估 / 央行购金 / 白银追踪 / **今日要闻** / 我的收藏）。用户想看新闻需要先点开「情报」再下钻，多 1 跳。

**问题 2**：V0.102 默认 6h 刷新一次（00/06/12/18 UTC ≈ 08/14/20/02 BJT），readhub 内部 API 1h ≈ 8-15 条新流，6h 抓一次覆盖率偏低。

**目标**：
1. 「今日要闻」从「情报」子页**提级**为顶级场景，排第 2 位（首页之后 / 决策之前）
2. scheduler 6h → 4h 加密（00/04/08/12/16/20 UTC ≈ 08/12/16/20/00/04 BJT）

## 关键设计

### 1. 顶 nav 8 scene 顺序

**V0.98 之前（14 链接平铺）** → **V0.98 7 顶 scene** → **V0.106 8 顶 scene**

```
🏠 首页  →  📢 今日要闻  →  📊 决策  →  💼 持仓  →  📰 情报  →  ⚙️ 配置  →  🤖 AI  →  🩺 数据健康
                                          (sub)              (sub)         (sub)        (sub)
```

**关键变化**：
- 「今日要闻」从「情报」子页**提级**为顶级场景（独立顶项，无 sub-tabs）
- 「情报」scene 子页从 5 个减到 4 个（**移除今日要闻**）
- 顶 nav 总数 7 → 8；独立顶项 3 → 4（首页 / 今日要闻 / AI / 健康）
- 决策 scene 仍是 4 subpages（趋势 / 打分 / 回测 / 复盘）

**Why 提级**：
1. V0.98 双层导航语义里，「顶级 scene = 高频入口 / 跨域场景」，「子页 = 同一主题下细分」；今日要闻是「独立主题」（新闻流），不属于「情报主题下的子分类」
2. 首页 + 决策 + 持仓是用户三大主操作；今日要闻作为"实时新闻"放在决策前，符合"看新闻辅助决策"的心智模型
3. 用户原话明确要求"首页之后 决策之前"的位置

### 2. scheduler 4h 节奏

| 项 | V0.102-V0.105 | V0.106 |
|---|---|---|
| `NEWS_FEED_INTERVAL_HOURS` | `6` | `4` |
| UTC 触发时刻 | 00/06/12/18 (4 点/日) | 00/04/08/12/16/20 (6 点/日) |
| BJT 触发时刻 (≈) | 08/14/20/02 | 08/12/16/20/00/04 |
| 日抓取次数 | 4 | 6 (+50%) |
| 日新增覆盖率 | ~32-60 条 | ~48-90 条 |

**Why 4h**：
1. 用户原话"每四小更新一次"明确要求
2. readhub 内部 API 1h ≈ 8-15 条新流；4h 抓一次 (32-60 条) 覆盖足够
3. fetch cache TTL 5min 仍能避免 scheduler + 手动 refresh 撞车
4. 性能开销：从 4 次/日 upsert → 6 次/日 upsert（DB write IO +50%）；当前 64378 行表 × 20 条/次 = 120 条/日，IO 微不足道

**动态化收益**：
```python
hours = tuple(range(0, 24, NEWS_FEED_INTERVAL_HOURS))  # (0, 4, 8, 12, 16, 20)
```
将来从 4h 改 3h 或 2h，只需改 1 个常量；日志 `hours_label` 自动同步。

## 与 V0.105 的连续性

V0.106 是 V0.105（类目筛选）的延续：
- V0.105 加类目筛选让「新闻分流」更有意义
- V0.106 把「今日要闻」从子页提到顶级 + 加密刷新频率，让「分流价值」被更频繁呈现
- 两者完全正交：类目筛选是「新闻内的过滤」，提级 + 4h 是「新闻入口的可达性 + 时效性」

**根因（用户体感）**：V0.105 加了类目筛选后，用户想看「科技」类新闻更频繁，但今日要闻仍藏在「情报」二级 nav 里，要 2 跳才能到；4h 刷新让新闻更"新鲜"。V0.106 把这两件事一起解决。
