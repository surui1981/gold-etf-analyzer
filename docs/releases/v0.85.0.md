# V0.85.0 · 数据时效迁移到 /data-health.html + 主页版面优化

## 用户原话
> 数据时效移动到数据健康页面，并对主页版面进行优化。

## 实施方向（用户选择）
**方案 A · 状态条瘦身 + 主页紧凑化**（4 个方案中推荐 · 风险最低）

---

## 视觉变化

**前（V0.84.0）**：
```
┌─ topnav row 1: [brand] [11 links]                              ~52px
├─ <details id="statusPanel">
│  summary: [🕒 纽约金·实时·04:30 ● | 上海金·... | 黄金ETF·...] | [⚠️ 投资警示 5 条要点 pill]  ~36px
│  ▼ click 展开：
│  body:    [5 条警示 bullets] [☐ 本次会话不再展开]
├─ <main content>
└─ (底部 warnFooter 已删除)
```

**后（V0.85.0）**：
```
┌─ topnav row 1: [brand] [11 links]                              ~52px
├─ <details id="statusPanel">
│  summary: [📊 数据健康: 5/7 实时 · 2 缓存 →]  |  [⚠️ 投资警示 5 条要点 pill]   ~36px
│  ▼ click 展开：
│  body:    [5 条警示 bullets] [☐ 本次会话不再展开]
├─ <main content>
├─ ▼ 「每日评估历史」默认折叠（点 summary 展开 ~340px）
│
└─ /data-health.html 单独页：完整 6 数据源视图
   ├─ statusPanel summary: 4 个 mini-chip（数据源 7 / 实时 4 / 缓存 1 / 演示 2）
   └─ 下方原 6 张市场卡视图保留
```

**收益**：
1. **非 health 页**：statusPanel summary 时效区从 3 个市场 chip 收成 1 个紧凑链接（chip 数 3→1，宽度 ~600px → ~140px）
2. **数据健康页**：summary 升级为「一眼看到整体健康度」4-chip，进入页面不再被 3 个市场时效重复披露刷屏
3. **主页 trend.html**：「每日评估历史」默认折叠，首屏省 ~290px（4 张极值卡 + 260px 图表 + 区间按钮全部进折叠体）
4. **决策链路**：用户进入 `/data-health.html` 一次就能看清 6 个数据源状态；其他 8 页只放「跳去看」入口，不再每页都重复同样的时效披露

## 改动清单

### C1 · 新增 1 个共享脚本

**`static/health-summary.js`**（新文件，~282 行）
- 自洽 IIFE 模块，挂载点 `#healthSummary`（与 V0.84 同模式）
- 数据源：`GET /api/v1/market/health`（每 60 秒自动刷新；失败时 60→120→300→600s 智能退避）
- 6 数据源状态聚合（live / stale / mock / unknown 4 类）
- 两种渲染模式：
  - **chip 模式**（8 页非 health）：`<a class="hs-chip-link" href="/data-health.html">`，显示 `5/7 实时 · 2 缓存 →`，`stopPropagation` 阻止冒泡到 `<summary>`
  - **panel 模式**（data-health.html）：`<span class="hs-panel">` 内 4 个 mini-chip（数据源 / 实时 / 缓存 / 演示），可扩展为 5 个（含未知）
- CSS 自注入：暗底 `.status-panel > summary` 上配色，与 freshness.js 的暗底 chip 风格统一
- 失败降级：保留末次数据 + 透明度 0.55（沿用 V0.83.4 freshness 的 `.fsh-stale` 模式）
- HC 高对比模式覆写：黑底黄字
