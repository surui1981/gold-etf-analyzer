## 〇 一页结论

这一版的起点不是 bug，是一句**投资框架**：

> 「我们考虑一个思路，来衡量金价，对比当前的评估参数有什么评估数值改进措施，
> 考虑一个核心标的，**资金的共识才是投资的价值**。」

⇒ 拆成三个可执行的问题：

| 问题 | 决定 |
|---|---|
| 用什么衡量？ | **核心标的 = COMEX/GLD 美元金价**（用户拍板）；人民币 518880 作交叉验证 |
| 改什么？ | **只修已确认的符号缺陷**（用户拍板）—— 不动权重、不动面权重、不动其它因子 |
| 怎么算「确认」？ | 方向性证据 + **可复算**（不是看一眼相关系数就下结论） |

结论：**6 个资金流因子里，有且只有 1 个的符号是反的** —— `cot_gold_net`
（CFTC 黄金管理基金净多占 OI %）。它原按「+」计分（净多越高 ⇒ 越利多黄金），
实测方向**正好相反**：**越拥挤 ⇒ 前瞻收益越差** ⇒ 自 V0.122.0 起改为 **「−」（拥挤度口径）**。

> ⚠ 这一版最值钱的不是那一个符号，而是**「怎么才算确认」的方法**，
> 以及方法本身推翻了三次中间结论 —— 详见 §二·2。

## 二、逐版本记录

### V0.122.0 · 资金流面 `cot_gold_net` 符号治本（拥挤度口径）

#### 1. 起因与口径

资金流面（V0.120.0 引入）有 6 个因子，全部按「值越高越利多黄金」或「值越高越利空黄金」
**二选一**打分 —— 方向烧在 `services/money_flow.py::MONEY_FLOW_FACTOR_RULES` 的
`positive` / `best` / `worst` 三件套里。

「**资金的共识才是投资的价值**」这句话对应到本项目就是一句话：
**CFTC 净多占 OI 是投机盘共识的度量 —— 但共识的方向不是「越多越买」，
而是「越挤越危险」**（拥挤 ⇒ 反转风险）。这与实测方向一致。

于是问题变成：**这个符号到底对不对？** 答案不能靠感觉。

#### 2. 测量的三层坑（方法本身就是这一版的产出）

直接算「因子 vs 前瞻收益的相关」会连续三次得出错误结论：

| 层 | 假象 | 表现 | 处理 |
|---|---|---|---|
| ① | **年份效应** | 年内前瞻收益高度持续 ⇒ 池化相关主要在测「年度共振」 | 前瞻收益**年内去均值**（年份固定效应） |
| ② | **重叠窗口机械伪相关** | `fwd_h` 与 `past_h` 共享端点 `P(t)` ⇒ **水平代理**天然「像回看、不像前瞻」（实测 corr(金价水平, 前瞻60) = **+0.10** vs corr(金价水平, 回看60) = **+0.33**） | **非重叠采样**（每隔 h 个交易日取一次）+ **控制当期金价水平**的偏相关 |
| ③ | **水平代理 ≠ 真预测** | 一个只是「当期金价代理」的因子，对回看的相关会同样强 | **前瞻/回看对称性检验**：|前瞻| 必须明显大于 |回看| 才算预测力 |

⇒ 最终判据 = **非重叠采样 + 年内去均值 + 控制当期金价水平 + 前瞻/回看对称性检验**。

> ②这一层是关键：它把 `dxy` / `real10y` 表面上「符号反了」的假象直接消掉了
> （控制金价水平后偏相关只剩 −0.02 / +0.02）⇒ **它们的符号是对的，不该动**。

#### 3. 实测结论（核心标的 GLD，可复算）

| 口径 | 数值 |
|---|---|
| 年内五分位的前瞻 60 交易日收益 | Q1（最不拥挤）**+6.45%** / Q5（最拥挤）**+0.62%** ⇒ **Q1 − Q5 = +5.84pp** |
| 分区间（2015-18 / 2019-22 / 2023-26） | **+10.46 / +4.86 / +1.75pp** ⇒ 三段同向 |
| 518880 人民币金价同口径 | 全样本 **+3.73pp**，三段同向 |
| 资金流面 composite 严格管线对照（h=60） | 现状 前瞻/回看偏相关 **+0.188 / +0.214**（回看主导 ⇒ 只是历史代理）→ 改号后 **+0.235 / +0.120**（**前瞻主导**） |
| 518880 composite 同口径 | 现状 +0.227/+0.134 → 改号后 **+0.252/+0.080** |

⇒ **改号**：`cot_gold_net` 的 `positive` 由 `True` 改为 `False`，
静态带 `best`/`worst` 对调（**best = P10 = 6.49%（不拥挤）**，
**worst = P90 = 34.10%（极度拥挤）**），**权重 18% 不动**。

复算入口：`python scripts/verify_cot_sign.py`（需联网：CFTC 年度包 + Yahoo GLD）。

#### 4. ⚠ 同时确认了「不该改的」与「证据的边界」

这一节是这一版**最容易被误读**的地方，所以写进文档而不是只写进注释：

- **不该改的**：其余 5 个资金流因子、11 个宏观因子逐一单独翻转后，
  「前瞻/回看」比值都 < 1.3 ⇒ 只是当期水平的代理，**不构成符号缺陷**，一律不动。
- **单因子本身不通过对称性检验**（h=60：前瞻 +0.027 vs 回看 +0.168）
  ⇒ 「净多占 OI」**不是独立的前瞻指标**，它只是资金流面 6 个因子里的一个。
- **效果在衰减**：2023-26 段相关已接近 0（GLD +0.03）；
  且 518880 在 2023-26 段**反向**（Q1−Q5 = −2.08pp）
  ⇒ 拥挤度口径**近期偏弱** —— 这是事实，不要当成稳定信号用。
- **短窗上不成立**：h=20/30 时 composite 的改善不出现，改善只在 h=60 体现。

#### 6. 守卫（防止符号被悄悄翻回去）

1. **不变式测试**：`for r in RULES: assert (best > worst) == positive`
   —— 静态带方向与 `positive` 标志**永远一致**；
2. **滚动路径测试**：造 80 条递增观测 ⇒ 滚动分位算出的 best/worst 方向
   必须与 `positive` 一致 —— 覆盖 `macro_thresholds.py` 那条**独立**的代码路；
3. **打分方向测试**：拥挤度口径下，净多越高分越低（单调递减）；
4. **复算脚本**：`scripts/verify_cot_sign.py` 能让方向证据本身被证伪。
