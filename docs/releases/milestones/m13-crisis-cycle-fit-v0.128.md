# M13 · 经济危机金价拟合曲线（V0.128）

> **一句话**：给仓库加了一个**「历史形态参照」**能力 ——
> 把历史危机周期的等权模板套到当前周期上，外推出一条**有方向**的路径，
> 并把「这条路径有多不可靠」摆在同一张卡上（drift=0 对照、各轮终点区间、锚点敏感度）。
>
> **发版区间**：V0.128.0 – V0.128.5 ｜ **状态**：活跃（最新里程碑）
> **本文件定位**：讲清「这个功能**为什么不是预测**」以及「它凭什么敢画一条有方向的线」。
> **口径真源**是 [../../crisis-cycle-fit.md](../../crisis-cycle-fit.md)（本文只讲取舍与教训）。
> **算法来源**：用户提供的 PM-Evaluator / gold-window-app `buildCycleFitAverage()` 核心逻辑
> （本仓库做了同构的纯 Python 实现，并加了 8 条证据门）。

## 一、数据从哪来（关键缺口与它的处理）

模板的信息量全在**旧危机周期**（1974 / 1980 / 1998 / 2008 …）上，而库里只有 2016 年以后。

⇒ 用户拍板：**从 PM-Evaluator 导出**（算法本就来自那里）。

⇒ 本版交付的是**产物槽位 + 校验器 + 降级链**：

- `src/app/assets/forecast/crisis_cycles.json`（**必须进版本库**，`data/` 被 gitignore）；
- **校验器**（`validate_cycles()`）：跳月 / 高点月不是最高月 / 与当前周期重叠 / 价格非法 ⇒
  **剔除并告警**，绝不静默修补；
- **有效周期 < 3 ⇒ 整个产物 `available=false`**（等权均值 ≈ 单轮，没有意义）；
- 产物没到位 ⇒ 接口 `available=false` + `reason` ⇒ 页面显示「待数据」+ 解释 ⇒
  **代码不等数据**（数据到位只影响「线上有没有曲线」，不影响能否把功能做完与验收）。

**导出格式契约**见 [../../crisis-cycle-fit.md §三](../../crisis-cycle-fit.md)。

## 四、证据门（E1–E8）与反向验证

| # | 断言 | 反向验证结果 |
|---|---|---|
| E1 | 无前视 | 单测钉住 |
| E2 | 锚点 = 日线最高收盘价所在月 | 单测 + API 用例 |
| E3 | 当前周期不进模板 | 单测：重叠周期被剔除并告警 |
| E4 | 曲线穿过当前点 | 单测 + API 用例（起点价 == 末月均价） |
| E5 | 锚点敏感度算出来并显示 | 单测 + 浏览器门禁 |
| E6 | drift=0 对照永远在 | **后端去掉 ⇒ API 用例变红；前端不渲染 ⇒ 浏览器门禁 3 条变红** |
| E7 | 无产物 ⇒ 待数据且不画曲线 | **伪造一条曲线 + 重启服务 ⇒ 浏览器门禁 3 条变红；API 用例 2 条变红** |
| E8 | 两个功能不混 | 浏览器门禁：形态拟合页无扇形图 canvas，扇形图页无形态拟合 canvas |

⚠ **反向验证时踩到的两个坑（都写进门禁头注了）**：

1. **浏览器门禁 mock 了接口 ⇒ 后端改动它看不见** ⇒ 后端的断言放在 API 用例里
   （那里直接 import 真代码）。
2. **浏览器门禁打的是活着的服务** ⇒ 改后端**必须先重启**再跑门禁，
   否则验的是旧进程里的代码 ⇒ 撤销改动门禁照样全绿（实测踩过一轮）。

## 五、教训

1. **用户给的算法自带免责声明 ⇒ 那是硬约束，不是注释** ——
   「历史形态参照 + 情景假设，不是预测」这条，决定了整页的措辞、字段名、接口契约
   （连 `signal` / `direction` / `target_price` 这类字段都不能出现在响应里，有断言钉住）。
2. **一个功能和另一个功能方向性相反时，不要放在同一个面板** ——
   扇形图与形态拟合并排 ⇒ 用户会把两条线当成「区间预测 + 目标价」；
   分开 + 页首写清区别，才是诚实的。
3. **假设参数必须常驻对照** —— drift=0 的终点不是一个「备选口径」，是「这条曲线里有多少是假设撑起来的」的答案。
4. **样本的脆弱点要自己算出来** —— 锚点 ±1 月的终点差；算不出来就写「算不出来」，不编数字。
5. **降级路径也要有证据门** —— 「没数据就不画」这条必须能被测出来（撤销 ⇒ 变红），否则它迟早被改回「画一条假线」。
6. **代码不等数据** —— 产物缺失时把整条链路做完（服务 / 接口 / 页面 / 门禁），
   数据到位只切「有没有曲线」这一个开关。
