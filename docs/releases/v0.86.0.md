## 改动清单

### C1 · 新增共享脚本

**`static/decision-explainer.js`**（新文件，~340 行）
- 自洽 IIFE 模块，提供 4 个工具函数 + 1 个 attach helper：
  - `breakdownRows(decision)` / `renderBreakdown()` — 综合指数按权加权拆解 + 公式行
  - `compareCard(decision)` — 「按当前建议应加减」对比卡
  - `tooltipFor(action, ctx)` / `renderTooltip()` — hover 决策行动的 3 行解释
  - `dimensionBars(components)` — 三维横向条形图（共振可视化）
  - `attachTooltip(anchorEl, action, decision)` — hover/focus 弹窗监听
- 字段名陷阱保护（V0.75.0 教训）：`trend_index.components` 缺失显示「— 未计入」
- i18n 兜底：`T(key, fallback)` 字典缺 key 时回退中文，绝不渲染 key 字面量

### C2 · synthesis-card.js 集成

- 决策行动 `.syn-action` 加 `class="de-action"` + `data-de-action` + `cursor:help`
- `.syn-bars` 后插入 `compareCard` + `renderBreakdown`
- `render()` 末尾自动 `attachTooltip` 到 `.de-action`（每次重渲染重新挂载）

### C3 · portfolio.html 集成

- 加载 `decision-explainer.js` script
- 决策面板 `.badge` 加 `class="de-action"` + `cursor:help`
- `position-rec` 后插入 `compareCard`；`buildComposition` 后插入 `renderBreakdown`
- `loadDecision()` 末尾 `attachTooltip` 到 `.de-action`

### C4 · trend.html 脚本加载

- 新增 `decision-explainer.js` script 加载（synthesis-card.js 依赖）

## 风险与缓解

| # | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| R1 | 字段名拼错静默渲染 undefined | 中 | 中 | hasOwn + 默认值保护 + `T(key, fallback)` 兜底 |
| R2 | trend_index.score=null 时拆解崩溃 | 中 | 中 | typeof === 'number' 守卫，缺失行显示「— 未计入」 |
| R3 | i18n key 漏 3 语 | 中 | 低 | check_i18n_keys.py + puppeteer 实跑 3 语（每组合 6 断言） |
| R4 | position_ratio 恒为 0 时对比卡显示「未录入本金」让用户困惑 | 中 | 低 | 回退到「建议重仓建仓至 X%」描述性文案，不伪造金额 |
| R5 | attachTooltip 监听累积（每次重渲染都挂） | 中 | 中 | 每个 anchorEl 挂新 tip 元素 + 离开时隐藏（不泄漏） |
| R6 | tooltip 元素遮挡下方内容 | 低 | 低 | position:absolute + z-index 9999 + mouseenter 后才显示 |
| R7 | 决策行动 chip 触发 hover 时被 statusPanel 遮挡 | 低 | 低 | chip 在 portfolio 主决策面板内，statusPanel 在顶部不冲突 |
