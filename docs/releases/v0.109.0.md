## 一句话

## 缺陷 1：`PE` 命中 `Europe` / `OpenAI`

### 成因

`PE`（市盈率）自 V0.105 起就在 `_FINANCE_KW`，而财经是**最高优先级**
（`财经 > 科技 > 创投 > 商业`）。分类器对英文只做子串匹配：

```python
def _hit(text, keywords):
    return any(kw.lower() in text for kw in keywords)
```

于是 `"pe" in "europe"` 为真，`"pe" in "openai"` 也为真。所有提到欧洲或
OpenAI 的新闻，无论主题是什么，都会落进财经。

V0.108.0 把财经词典从 32 词扩到 100+ 词、把白名单站名写进词典，这套
「站名/短词即信号」的设计**放大**了这个既有缺陷 —— 不是 V0.108.0 引入的
bug，但它在 V0.108.0 之后才被量化出来。

### 实测影响

生产 DB 576 条全量对拍（修复前朴素匹配 vs 修复后 classify）：

```
  → 财经 → 科技: 28     ← 全部是科技新闻被误判
     财经 → 财经: 226
     科技 → 科技: 174
     商业 → 商业: 6
     创投 → 创投: 4
  → 科技 → 其他: 1
  → 财经 → 其他: 1

总变化 30/576 (5.2%)
```

28 条误判的实例（全部是真科技新闻）：

```
Oppo has a plan to crack the European smartp...    （European）
突发，GPT、Claude 余额一夜清空！OpenCode 爆雷
Claude 反抗人类，连改 20 次底层宪法，拒绝部署训练
AWS Will Run Its European Sovereign Cloud Wi...
谷歌开源 Harness，支持 OpenCode 和 Codex
Windows 11 is getting what should be a hefty...
华硕 ProArt P14/P16 首发 18999 元起：搭载 RTX Spark
```

触发词统计：`PE` 单独造成 28 条、`ETH+PE` 1 条、`PMI` 1 条。

### 修法

**长度 ≤3 的纯 ASCII 词改走词边界正则**，其余（长英文词 / 全部中文词）
保持子串匹配：

```python
_BOUNDARY_PATTERNS = {
    kw: re.compile(rf"(?<![a-z]){re.escape(kw.lower())}(?![a-z])")
    for kw in (*_FINANCE_KW, *_TECH_KW, *_VC_KW, *_BIZ_KW)
    if kw.isascii() and len(kw) <= 3
}   # 37 词
```

边界表的 37 词：`PE ETH ETF BTC AI GPU CPU AMD IBM GPT 5G 6G 3nm 5nm
7nm AGI IPO VC FA GP LP BP CEO CFO COO CTO ECB BoJ IMF WTO GDP PMI QE
G7 G20 M&A`

**设计取舍**：

| 写法 | 结果 | 理由 |
|---|---|---|
| `2026PE` | ✅ 命中 PE | 数字不是字母边界 —— 中文财经报道常见写法 |
| `科创50ETF` | ✅ 命中 ETF | 汉字不是 ASCII 字母边界 |
| `pe(ttm)` / `静态 pe` | ✅ 命中 | 括号/空格不是字母 |
| `OpenAI` / `Anthropic` | ✅ 不受影响 | 长词不在边界表，仍走子串 |
| `Europe` / `European` / `shape` | ❌ 不再误命中 PE | 核心修复 |
| `Ethiopia` | ❌ 不再误命中 ETH | 同类一并修 |
| `AIGC` | ✅ 显式补词 | 否则 `AI` 因后接字母 G 被边界拒掉 |

复合词显式补齐：`AIGC` / `AGI` / `GPU云` / `算力云`。

## 缺陷 2：中文裸词「发布」

### 成因

中文没有词边界，`"发布" in text` 会命中一切含「发布」的文本。这正是
V0.108.0 release notes 里记录的「已知问题 1」。

### 实测影响

生产数据里仅靠「发布 / 新品 / 签约」这类泛词落到商业的共 5 条，其中 4 条
是噪声：

```
[发布] 准备去看彩叶了吗？北京警方发布彩叶观赏季安全提示
[新品] 喜报！竹山 3 家科技小院获省级认定
[发布] 中央档案馆向社会集中开放 5000 余件长征专题档案
[发布] 俄罗斯称袭击乌克兰敖德萨地区四艘货船及雷尼港设施
```

### 修法与影响面对照

裸词 `发布` → `发布会` + `发布公告`。

移除裸词后**失去唯一商业依据的恰好就是那 4 条噪声**，而生产数据里 7 条
真正的「发布会」商业新闻全部保留。修得干净，没有误伤。

### 写测试时被实测纠正的两处

两条测试初版写错了，是代码对、预期错：

- `classify("比特币突破", "", "")` 期望命中英文缩写 `BTC` —— 纯中文文本
  本就不会字面出现 `BTC`。改用 `btc 突破新高`。
- `classify("OpenCode 2.0 正式发布", ...)` 期望科技 —— `OpenCode` 不在
  科技词典里，命中的是「发布」判商业（与缺陷 2 同源）。改用
  `Oppo 计划进军欧洲智能市场`，正对应 `PE ⊂ European` 的修复目标。

## 遗留

需要跑一次全量 sweep（不只是「其他」，而是**所有行**）：
