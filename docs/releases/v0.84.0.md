# V0.84.0 · 状态条方案 C · 数据时效 + 警示合并 1 行

## 用户原话
> 数据时效，投资警示，可以作到 1 行，并且进行合并显示给信息提供更好的显示版面。
> 献给我思路我决定执行方向。

## 实施方向（用户选择）
**方案 C · 单一 disclosure 统一处理**（4 个方案中推荐 + 节省最多版面）

## 视觉变化

**前（V0.83.4）**：
```
┌─ topnav row 1: [brand] [11 links]                              ~52px
├─ topnav row 2: [🕒 时效 chips]  [⚠️ 投资警示按钮]                  ~36px
├─ <main content>
└─ <details id="warnFooter"> [5 条警示 bullets] [dismiss]         ~80px（展开时）
```

**后（V0.84.0）**：
```
┌─ topnav row 1: [brand] [11 links]                              ~52px
├─ <details id="statusPanel">
│  summary: [🕒 时效 chips]  |  [⚠️ 投资警示 5 条要点 pill]            ~36px
│  ▼ click 展开：
│  body:    [5 条警示 bullets] [☐ 本次会话不再展开]
├─ <main content>
└─ (底部 warnFooter 已删除)
```

节省 ~80px（删 1 行 nav + 删底部 details），用户首次访问看到 1 行而非 3 行。

## 改动清单

### 新增 1 个 i18n key × 3 语
| key | zh-CN | en-US | zh-TW |
|---|---|---|---|
| `status.warn_pill_label` | 投资警示 | Notice | 投資警示 |
| `status.warn_pill_unit` | 条要点 | points | 條要點 |

合计 2 keys × 3 langs = 6 条。**不用** `{n}` 参数化（拆成 label + count + unit 三段，避免 i18n 参数复杂度）。

### JS 改动
- **`static/topnav.js`**：删除 row 2 `.topnav-meta` 注入；只保留 1 行 brand + 11 links
- **`static/warning.js`**：监听 `#statusPanel`（不是 `#warnFooter`）；动态根据 `<ol>` 实际 li 数写 `[data-warn-count]`；**新增 `hashchange` 监听**（同页 hash 跳转也响应 `#status` 深链）
- **`static/i18n.js`**：修 init() 漏 `await loadLang(saved)` bug——saved=非 zh-CN 时 reload 仍显示中文
- **`static/freshness.js`**：未改动（mount 点 `#freshnessInline` 仍可用，只是不在 topnav-meta 而在 statusPanel summary 内）

### 9 个 HTML 页面
- 删除 `.topnav-meta` CSS
- 删除 `.warn-footer` CSS（替换为 `.status-panel` CSS）
- 移除 `<details id="warnFooter">` 块
- 新增 `<details id="statusPanel">` 块在 topnav script 紧后
- 保留 4 页（silver/data-health：蓝 accent #1d4ed8；其他：金 var(--accent)）
- 保留 8 页（backtest/central_bank/silver/data-health）的页面特定 i18n keys

### 其他
- **`static/theme.css`**：HC 高对比模式 `.warn-footer` 覆盖 → `.status-panel` 覆盖
- **`scripts/check_cluster_render.mjs`**：V0.83 C4 段重写为 V0.84 段（断言 statusPanel / 计数 / 折叠态）
- **`static/sw.js`** / **`pyproject.toml`** / **`src/app/__init__.py`**：版本 v0.83.4 → v0.84.0

## 风险与缓解

| # | 风险 | 缓解 |
|---|---|---|
| R1 | 旧 .warn-footer / .topnav-meta 引用残留 | 9 页面 grep 检查 0 残留；cluster_render 断言无引用 |
| R2 | dismiss 后同页 #status 跳转不响应 | warning.js 加 `hashchange` 监听 |
| R3 | saved=非 zh-CN 时 reload 仍回退到 zh-CN | i18n.js init() 加 `await loadLang(saved)` |
| R4 | 折叠态 body 部分浏览器不自动 hide | 显式 `.status-panel:not([open]) > .status-body { display: none }` |
| R5 | `[data-warn-count]` 被 i18n.js apply 覆盖 | 该 span 无 data-i18n，由 warning.js 单独控制；i18n.js 跳过 |
| R6 | 警示标签用 warn.title 含 ⚠️ emoji 致双 emoji | 用 status.warn_pill_label（无 emoji），由 .warn-pill-icon span 单独控制 ⚠️ |
| R7 | cluster_render.mjs V0.83 C4 段断言旧 markup | 重写为 V0.84 段 |
| R8 | news.html 用旧 .w-title 模式不受影响 | 保留 warn.title / warn.collapse_toggle keys（仅 news.html 引用） |
