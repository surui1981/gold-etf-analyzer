# V0.100 · 消息面未打分 → 综合指数 pending

> 用户原话：「V0.99版本我要进行评估分数的改进， 综合分数得分需要完成消息面打分完成 才能在应用生成提供，不然只输出参数评分」
> 范围：① NewsScoreOut/NewsIndexOut.score 改 `float | None`（未打分 = None，替代中性 50 兜底）；② TrendService 把 news=None 走既有剔整面归一化路径；③ trend.html + silver.html 两评估页加「参数分两栏 + 综合分 pending chip」；④ 4 处版本同步 0.99.0 → 0.100.0。

## 背景

**为什么做 V0.100**：

- 当前 `TrendService._analyze_uncached`（trend.py:495-498）**默认** `news_score = 50.0`（中性兜底）；`NewsScoreService.get_today()` 当日无打分时由 `aggregate_slots()`（news.py:79-93）返回 `NEUTRAL_SCORE=50.0`。
- 结果：用户**未打分**的消息面会以「中性 50」自动参与综合指数，按 NEWS_WEIGHT=0.30（macro.py:79）稀释 15 分 —— **与用户「未完成消息面打分则不输出综合分」诉求直接矛盾**。
- `NewsIndexOut.score: float`（market.py:193-199）schema 层不允许 None；`NewsScoreOut.score: float`（schemas/news.py:82-106）同样。
- 既有「剔整面 + 归一化」算法（trend.py:517-524，`valid_faces` + `face_w` 归一化）已实测覆盖「tech 整面缺失」场景（`test_trend_combined_none_when_all_insufficient` L462-479），**news=None 可走同一分支**——不需新算法。

**用户已确认的 4 个关键决策**：
1. 「消息面打分完成」 = `NewsScoreService.get_today().scored == True`
2. 未完成兜底 = 综合指数标 pending，应用层只展示技术+宏观分
3. 范围 = `trend.html` + `silver.html`（`gold.html` 不存在）
4. 展示 = 参数分（如技术面 65）+ 综合分 pending chip 两栏

**设计纪律**：
- 不引新依赖
- 不动宏观面（macro.py 已结构化恒有值）
- 不动技术面 5 维逻辑
- 不动 GoldTrendOut / SilverTrendOut 顶层 schema 结构
- 不改既有「剔整面 + 归一化」算法（保留 V0.78.0 Step D 实测覆盖）
- 消息面 None 触发条件 = `NewsScoreOut.scored == False`（= `bool(records)`，news.py:161）

## 5 个 commit（一个 PR 顺序）

### C1 · 数据层（schema + 服务常量）`cf63b7f`

**问题**：`NewsScoreOut.score: float` schema 层不允许 None；`aggregate_slots` 默认 `NEUTRAL_SCORE=50.0` 兜底。

**修法**：
- `src/app/schemas/news.py:87-90` `NewsScoreOut.score: float | None`、`direction: DirectionSignal | None`
- `src/app/schemas/market.py:193-210` `NewsIndexOut.score: float | None` + 新增 `pending_reason: str | None`
- `src/app/services/news.py:36` 删 `NEUTRAL_SCORE = 50.0` 常量
- `src/app/services/news.py:79-93` `aggregate_slots()` 未打分返回 `(None, "", False)`
- `src/app/services/news.py:47-60` `direction_of(None) → None`（防 TypeError）
- `tests/test_services/test_news_service.py:22-33` `test_default_neutral_without_history` 断言改 `is None`

**关键不变量**：
- `NewsScoreOut.scored: bool` 保持为唯一真源（前端 pending chip 触发依据）
- Pydantic v2 自动接受 `float | None`，无需 validator
- `news_score = None` 让「不注入 news service」与「注入但 scored=False」同形
