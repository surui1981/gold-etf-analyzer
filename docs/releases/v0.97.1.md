# V0.97.1 · /ask 工具调用展示调整（UI hotfix）

> V0.97.0 后的 UX 调整版。仅前端展示层，无后端逻辑 / DB / API 变化。

## 背景

V0.97.0 部署后用户实测反馈：

1. **工具调用完成后还在显示 spinner** —— 聊天流里 assistant 消息因 `content` 为空 + `tool_name` 命中分支，永久展示「正在调用工具: get_market_overview...」文案
2. **tool 结果在聊天流里直接显示原始 JSON** —— 1KB+ 的 JSON 字符串塞在消息流里，既不友好也暴露内部结构
3. **右侧 trace 面板用英文 tool 名 + 原始 JSON** —— `get_market_overview` 是开发者术语；用户看到「这个」不知道是干啥的
4. **缺少「模型答案是否基于实时数据」的验证提示** —— 用户看到 assistant 回答后无法判断「这个数字是我编的还是查的」

## 5 项交付

### 1. Tool name 中文化 + emoji 标签（`TOOL_LABELS` 字典）

| 英文 | 中文 |
|---|---|
| `get_market_overview` | 📈 市场概览 |
| `get_scoring_summary` | 🎯 评分汇总 |
| `get_user_portfolio` | 💼 持仓查询 |
| `get_warning_summary` | ⚠️ 警示 |
| `get_etf_recent_flows` | 💸 ETF 资金流 |

### 2. Tool 输入摘要（`summarizeInput`）

按 tool 白名单抽取关键参数：
- `get_scoring_summary` → "2026-10-01 → 2026-10-14"
- `get_etf_recent_flows` → "近 30 天"
- 未知 tool → 原 JSON 截断 100 字符

### 3. Tool 结果摘要（`summarizeResult`）

按 tool 白名单抽取核心数据（1-2 行可读）：
- `get_market_overview` → "ny: 2400 (+0.5%) · shanghai: 480 · hushen: 5.85"
- `get_scoring_summary` → "近 30d T+0/T+1/T+3/T+5: 35.7% / 40.7% / 40.0% / 39.1% · 最佳: t1"
- `get_user_portfolio` → "成本 100000 · 市值 105000 · 浮盈 +5000 · 收益率 5.0%"
- `get_warning_summary` → "N 个市场状态"
- `get_etf_recent_flows` → "30 天 · 最近: 2026-10-14"
- 未知 tool → 原 JSON 截断 200 字符

### 4. 聊天流展示调整

| 旧 | 新 |
|---|---|
| assistant tool_use 消息显示「⟳ 正在调用工具: get_market_overview…」spinner | 显示「🔧 📈 市场概览」chip（响应已完成，不再 spinner） |
| tool 消息直接渲染 `<pre>{...1KB JSON...}</pre>` | 折叠 `<details>` 默认收起，summary 显示「📈 市场概览 · 关键摘要」，展开看原始 JSON（限 280 字符 max-height + 滚动） |
| 最终 assistant 无数据来源提示 | 末尾追加「📊 基于 N 个工具调用 · 右侧查看详情」chip（虚线边框，弱提示） |

### 5. 右侧 trace 面板重做

每条 trace item 展示：
- 工具名（中文 label + 角色 chip：`→ 调用` / `← 结果`）
- 参数摘要（`summarizeInput` 输出）
- 结果摘要（`summarizeResult` 输出）
- 折叠「原始 JSON」（`details` 默认收起，展开看 ≤800 字符原始数据）

## 设计纪律

- **不修改任何后端逻辑 / API 契约** —— 纯前端展示层
- **数据可追溯**：每个 assistant 答案下方都标注「基于 N 个工具调用」，右侧 trace 面板可逐条验证数据来源
- **不破坏 XSS 防护**：marked 渲染仍走 `sanitizeHtml` 清洗
- **不破坏 i18n**：i18n key 复用，未新增（`ai.calling_tool` 旧 spinner 文案删除后无引用，保留 key 不影响）
- **响应式保留**：手机端 `< 1000px` 隐藏 trace 面板规则不变

## 部署

- LAN 部署：浏览器 hard-refresh 一次（Ctrl+Shift+R）拉新 SHELL_CACHE
- 已安装 PWA：SW 检测到 `v0.97.0` → `v0.97.1` 变更，自动 activate 重建缓存
- 后端无变更，uvicorn 无需重启

## 不在本版
