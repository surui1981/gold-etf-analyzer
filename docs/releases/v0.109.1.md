# V0.109.1 · 分类架构改为「内容优先、站名兜底」

> 发版日期：2026-10-20
> 前置：V0.109.0（词边界 + 发布词精度）
> 性质：修正 V0.108.0 的设计失误

## 一句话

V0.108.0 把 33 个优质站名写进了内容关键词词典，而财经优先级最高 ——
于是**站名压过内容**，实测生产 DB 里 160 条（27.8%）纯靠站名定类，
「印度东部踩踏致 17 人死亡」因为发稿站点是财联社而混进财经流。
V0.108.0 那个「财经 226 条」的漂亮数字主要是假象。

---

## 问题

### 证据

V0.108.0 的 `classify()` 把站名和标题摘要拼成同一个字符串再匹配：

```python
text = f"{title} {summary} {site_name}".lower()   # ← 站名与内容同池
if _hit(text, _FINANCE_KW): return "财经"           # 财经优先级最高
```

V0.108.0 新增的 25 个白名单站名进了这四个词典，于是站名成了最高优先级
信号。生产 DB 576 条全量对拍：

| 来源 | 内容未命中词典、纯靠站名定类的条数 | 内容样例 |
|---|---|---|
| 格隆汇 | 35 | 法国内政部长努涅斯 / 伊拉克总部爆炸 / 胡塞武装发言人 |
| 财联社 | 26 | 印度东部踩踏致 17 人死亡 / 伊拉克弹药仓库爆炸 |
| 第一财经 | 23 | 法国多地大规模抗议 / 利比亚西部爆炸 |
| 华尔街见闻 | 14 | 胡塞武装空袭也门致 9 死 / 特朗普指示收看右翼广播 |
| techradar.com | 18 | Sony Bravia 9 II 评测（**这条是真科技新闻**） |
| IT 之家 | 17 | 多为新品短标题 |

合计 182 条纯站名定类。

### 两条实测结论

1. **通讯社那一档（约 100 条）全是与财经无关的国际新闻**，该丢
2. **科技垂直站那一档（约 60 条）是真科技新闻**，该留

分界线不是「财经 vs 科技」，而是**垂直媒体 vs 综合通讯社**。

---

## 另一条推翻 V0.108.0 立论前提的实测

V0.108.0 加白名单的理由是「readhub 上财经源经常给空摘要，站名即最可靠信号」。
**但那 182 条里没有一条内容字段为空。**

所以「白名单是为了救空摘要好新闻」这个前提在生产数据上并不成立 ——
收益全部来自科技垂直站（英文评测天然没有中文关键词）这一半。

## 改法

### 两段式分类

```
内容优先   title + summary 命中 4 类词典，优先级 财经 > 科技 > 创投 > 商业
站名兜底   内容一条都没命中时，查 _SITE_HINTS
弃入       都落空 → 「其他」，fetcher 不入库
```

### 站名兜底只对垂直媒体开放

站名要能代表**选题范围**才配当信号：

| 类型 | 站点 | 兜底 |
|---|---|---|
| 财经垂直媒体 | 金十数据 同花顺财经 金融界 中国证券报 上海证券报 证券时报 每日经济新闻 | ✅ |
| 科技垂直站 | techradar 9to5Mac IT 之家 快科技 C114 钛媒体 品玩 爱范儿 机器之心 雷峰网 虎嗅 极客公园 量子位 zdnet theblockbeats techflowpost 蓝点网 infoq 36 氪 | ✅ |
| 创投垂直媒体 | 36Kr 36氪 创业邦 投资界 铅笔道 IT桔子 | ✅ |
| 综合通讯社 | 财联社 格隆汇 第一财经 界面新闻 经济观察报 华尔街见闻 | ❌ |

通讯社发纯市场内容时仍会被**内容词典**命中（不靠站名），只是内容无关时
必须掉进「其他」。这正好对应用户诉求「主要聚焦国内国际的财经新闻」——
国际财经保留、国际战事灾难丢弃。

### 最长匹配优先

readhub 的 `siteName` 常带后缀（`C114 通信网` / `IT之家`），子串包含即可命中，
更长的站名压过更短的前缀。

### 33 个站名移出内容词典

含 V0.105 起就在的 4 个：财联社 / 华尔街见闻 / 格隆汇 / 金十数据。

指数名（`中证` `上证` `深证` `创业板` `科创板` `沪指` `深成指`）**不是站名**，
保留在 `_FINANCE_KW`。

## 实测结果

生产 DB 576 条全量：

```
科技 248 / 财经 58 / 商业 27 / 创投 5
→ 入流 338
→ 弃入「其他」114
→ 黑名单站点（新浪科技 / maomu.com）不入流 124
```

**国际财经保留**：

```
财经  韩国财长：半导体市场景气至少维持至明年
财经  欧洲央行维持利率不变 拉加德发表讲话
财经  OPEC+ 宣布延长减产协议
```

**国际战事灾难丢弃**：

```
其他  印度东部踩踏事故致 17 人死亡        [财联社]
其他  伊拉克首都一弹药仓库发生爆炸        [财联社]
其他  法国多地发生大规模抗议 数百人被捕   [第一财经]
其他  格隆汇｜胡塞武装发言人：沙特战斗机对萨那发动袭击
```

## 测试

新增 7 例（`TestContentFirstSiteFallback`），分类器 51 → 58，全量 **115 passed**。

修正 2 例编码了旧行为的断言：

- `test_classify_empty_title_uses_site_name`（V0.105 起）原用「华尔街见闻」，
  实测该站也发战事新闻，已移出兜底表。改用财经垂直站正向断言 +
  3 家通讯社负向断言。
- `test_classify_whitelist_finance_site_v01080`（V0.108.0）原断言 10 个财经站
  全部兜底，改为「7 家财经垂直媒体兜底」，通讯社那 3 家移入负向用例。

### 三处预期在写完后被实测纠正

代码是对的，测试预期写错了：

1. `某芯片公司完成 B 轮融资` → **科技**：科技 > 创投 是既定优先级，
   「芯片」先命中。补一条无「芯片」的 SaaS 版本才测得到创投
2. `_SITE_HINTS` 漏加进 import → `NameError`
3. `韩国财长：半导体市场景气至少维持至明年` 标题单独看只命中「半导体」（科技），
   财经信号全在**摘要**（财政部/基金/经济/世界银行）—— 改用生产库真实摘要，
   写成 `(标题, 摘要, 来源)` 三元组，顺带证明内容优先确实吃到摘要

## 历史数据 sweep

本次改了分类逻辑，DB 里 576 条仍带旧分类。`upsert_bulk` 遵循「已分类行不变更」
纪律，所以只有新抓的条目用新逻辑。

新增 `scripts/reclassify_v01090.py`，**默认 dry-run**，确认后才写库：

```bash
# 先看会发生什么
PYTHONPATH=src:. .venv/bin/python scripts/reclassify_v01090.py

# 确认后执行（只改分类）
PYTHONPATH=src:. .venv/bin/python scripts/reclassify_v01090.py --apply

# 连同黑名单站点存量行（新浪科技 122 + maomu.com 2）一起清理
PYTHONPATH=src:. .venv/bin/python scripts/reclassify_v01090.py --apply --drop-blocklisted
```

与 `reclassify_v01071.py` 的区别：后者只扫 `category='其他'` 的行，修不了
「被误判成财经的 28 条科技新闻」——本版扫**所有行**。

脚本会自动重建所有受影响日期的 `news_feed_daily`。
