## 四、教训沉淀（V0.100.1 教训的首次兑现）

V0.100.1 hotfix 沉淀的 [v01001-sw-bump-on-static-change.md](../../.claude/projects/-home-surui-gold-etf-analyzer/memory/v01001-sw-bump-on-static-change.md) 明确「改 static 必须 bump」 —— 这次是首次在功能 commit（不是正式发版）中直接应用该教训：

1. 改 home.html + home.js 第 1 步就 bump sw.js VERSION（不是事后补）
2. 同步 bump `__version__` + `pyproject.toml` + CHANGELOG（4 处同步清单一气呵成）
3. sw.js activate 阶段 stale 清理同步更新

无 SW 缓存漂移、无需后续 hotfix 救火。
